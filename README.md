# illusorys Publisher Website

A dependency-free static website prepared for GitHub Pages.

## GitHub Pages

The intended public repository is `illusorysn/illusorysn.github.io` and the resulting
URL is `https://illusorysn.github.io/`.

Upload the contents of this directory to the repository root. In the repository's
**Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

The public support address is `illusory9212@gmail.com`.
